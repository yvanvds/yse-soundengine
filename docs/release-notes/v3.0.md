# libYSE 3.0 — release notes (draft)

Draft body for the v3.0 GitHub release. Paste it into the release, or pass it
to `gh release edit v3.0.0 --notes-file docs/release-notes/v3.0.md` after
`release.yml` has published the tag. Keep it in step with the upgrade guide,
`documentation/source/upgrading.rst`, which has the full detail.

---

libYSE 3.0 is a major release: about 440 commits since v2.4.0. It grows the
patcher from 42 to 305 objects, replaces the render fan-out with a task-graph
scheduler, audits the C API end to end, and rewrites most of the
documentation. It also changes the C ABI and several behaviours, so **read
[Upgrading from 2.4 to 3.0](https://yvanvds.github.io/yse-soundengine/upgrading.html)
before you update.**

## Breaking and behaviour changes

The upgrade guide has every change, with its issue number. The ones most
likely to affect you:

- **Default sample rate is 48 kHz** (was 44.1 kHz). Ask for a rate with
  `System().requestSampleRate()` / `yse_system_request_sample_rate()` before
  `init()` (#646).
- **`System().init()` returns `false` when no audio device opens.** Headless
  hosts should use `initOffline()` (#973).
- **`autoReconnect` delay is in milliseconds**, not `update()` ticks (#681).
- **A default-constructed `device` has ID `-1`**, and `getDevice()` throws
  `std::out_of_range` (`NULL` in C) for an out-of-range index (#666, #581).
- **C ABI:** `yse_patcher_init`, `yse_patcher_parse_json`, `yse_clip_bind`
  and `yse_system_create_clock` return `YseStatus` (#910);
  `yse_channel_get_name` copies into a caller buffer (#905); the scripting
  functions and three callback typedefs are renamed (#911); patcher ID and
  inlet queries answer `YSE_PATCHER_ID_NONE` / `YSE_PATCHER_INLET_NONE`
  instead of 0 (#732, #736).
- **Patcher bus addresses are `patcher.<name>.<slot>`.** Host code that
  publishes to or subscribes on patcher slots must add the prefix (#894).
- **Patcher object behaviour:** `.route` strips the matched selector and
  matches floats, and a bare `.route` has a `0` outlet (#672, #679);
  `.metro` applies period changes while running and accepts `bang` / `stop`
  / float on the left inlet (#625, #711); `~saw` is bipolar (#955); several
  `~dac` objects sum (#932); `.counter` honours its start value and step
  inlet (#956); message boxes send the typed message they spell (#933).
- **Patch files:** object IDs are numbered per patcher from 0, so patches
  save reproducibly; 2.4 patches still load (#730, #733). `ParseJSON` adds
  to the patcher and rolls back a failed load (#938, #939).
- **Random numbers:** a thread-safe, real-time-safe generator replaces
  `rand()`. `RandomF()` is now `[0, 1)`, `Random(0)` returns 0, and `srand()`
  no longer seeds the engine; use `YSE::Randomize()` / `YSE::RandomSeed()` or
  `yse_randomize()` / `yse_random_seed()` (#410, #908).
- **Render threads:** auto-sized to physical cores − 1 (max 8) and
  configurable with `System().renderThreads()` /
  `yse_system_set_render_threads()`; `0` renders on the audio thread alone
  (#861).
- `channel::setVirtual(false)` now switches virtualisation off (#864), and
  `midiOut::Raw()` sends the whole message instead of exactly three bytes
  (#748).

## Highlights

### Patcher

- **305 objects** (up from 42), following Max's object set: comparison,
  bitwise and math operators, `.expr` / `.vexpr` / `.if`, routing
  (`.sel`, `.trigger`, `.router`, `.matrix`),
  randomness (`.drunk`, `.urn`, `.prob`), time (`.pipe`, `.line`,
  `.speedlim`, `.timer`, `.clocker`, `.transport`, `.tempo`, `.timepoint`),
  lists (`.zl`, `.pack`, `.unpack`, `.iter`, `.join`) and symbols
  (`.sprintf`, `.regexp`, `.tosymbol`).
- **Subpatchers**, with control-rate `.inlet` / `.outlet` and audio-rate
  `~inlet` / `~outlet` (#545, #764).
- **Data stores:** `.coll`, `.table`, `.funbuff`, `.bag`, `.value`,
  `.qlist`, `.mtr`, `.seq`, `.textfile`, and the `.dict` and `.array`
  value types with their object families, with file I/O off the audio
  thread.
- **MIDI:** input and output families, `.midiparse` / `.midiformat`, SysEx,
  RPN/NRPN, MPE, `.makenote`, `.poly`, `.borax`.
- **GUI controls** with a structured, settable value protocol: `.dial`,
  `.rslider`, `.multislider`, `.matrixctrl`, `.kslider`, `.function`,
  `.xyslider`, `.umenu` / `.radiogroup` / `.tab`, and `.preset` to snapshot and recall them (#551, #564).
- **Domain clocks** drive `.metro`, `.delay`, `.seq` and `.qlist` in
  tempo-relative time.

### Engine

- Task-graph render scheduler: channels, voice slices and returns render in
  parallel, bit-identical at any worker count, with cost-driven balancing
  and placement on performance cores (#859–#862).
- `System().requestSampleRate()`, `System().setChannelConfiguration()` for
  offline sessions, and `System().renderThreads()`.
- Race and lifetime fixes across sounds, streaming, channels, clocks, clips
  and the patcher.

### C API

- Around 60 new functions, including the global named bus
  (`yse_bus_publish_*`, `yse_bus_subscribe`), sound and channel names,
  patcher names and subpatchers, occlusion and patcher send callbacks,
  `yse_midi_out_raw`, multichannel buffers, reverb presets, render thread
  control and RNG seeding.
- No C++ exception escapes an `extern "C"` function; failures report
  through `yse_last_error()`.
- The headers compile as C99 (#976).

### Documentation

- New getting-started pages on the mental model, threading, and sessions
  and devices.
- A full patcher guide (messages, building graphs, file format,
  subpatchers, host I/O, time, data, MIDI, GUI, real-time model, extending)
  with a generated per-category object reference and five patcher
  tutorials.
- A C API guide ahead of the reference, and a clocks and clips tutorial.

### Packaging

- `NOTICE` lists every third-party component, and the Windows and Android
  archives ship the bundled libraries' licenses and LGPL sources
  (#892, #979).
- The unused vendored cJSON is no longer compiled into `libyse`, so its
  `cJSON_*` symbols are gone from the shared library. JSON goes through
  nlohmann/json, as before (#984).
